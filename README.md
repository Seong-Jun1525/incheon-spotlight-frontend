# 인천스팟 (Incheon Spotlight)

2026년 인천 11개 구·군을 3D 지도로 탐색하고, 관광정보·주변 음식·숙박·날씨·이동 경로·AI 코스를 연결하는 관광 웹 서비스입니다.

## 운영 환경

- 운영 URL: https://incheon-spotlight.tail59297d.ts.net/

## 핵심 기술 스택

| 구분 | 기술 |
| --- | --- |
| 프론트엔드 | React 19, Vite, React Router |
| 3D·실지도 | React Three Fiber / Three.js, Cesium |
| 상태·데이터 | Zustand, TanStack Query |
| 다국어 | i18next (한국어, 영어, 일본어, 중국어) |
| 배포 | Docker, Nginx |
| 외부 연동 | 한국관광공사 TourAPI, 기상청 날씨, TMAP 경로, Ollama |

## AI 모델

추론은 Ollama에서 실행합니다. 운영 기본 모델은 아래와 같습니다.

| 용도 | 모델 |
| --- | --- |
| 여행 상담, 추천 코스, 여행 일정 | qwen3.5:4b |
| 방문 사진 검토 | qwen2.5vl:3b |

## 구현된 기능

- **3D 구·군 탐색** — 인천 11개 구·군 디오라마에서 구역을 고르고 명소·추천 코스를 둘러봅니다.
- **관광정보 검색** — TourAPI 키워드·장소 유형으로 명소를 찾고, 상세 정보와 주변 음식·숙박을 확인합니다.
- **축제·날씨** — 구·군 기준 축제와 기상청 날씨·미세먼지를 지도 화면에 표시합니다.
- **실지도·이동 경로** — Cesium 지도에서 장소와 코스를 보고, TMAP 경로로 이동 동선을 확인합니다.
- **AI 여행 가이드** — 채팅으로 여행 질문을 하고, 조건에 맞는 코스와 오늘의 코스를 생성합니다.
- **여행 일정** — 동행 유형·일정·선호를 넣어 여행 계획을 만들고 저장·조회합니다.
- **방문 인증·스탬프** — 사진으로 방문을 인증하고, 구·군 스탬프 패스포트와 공개 방문 피드를 봅니다.
- **회원** — 이메일 인증 회원가입, 로그인, 비밀번호 재설정, 프로필, 즐겨찾기, 알림을 제공합니다.
- **관리자 검토** — 자동 인증이 어긋난 방문 건을 관리자가 다시 처리합니다.
